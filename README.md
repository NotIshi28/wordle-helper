# Wordle Helper

Stuck while solving the daily [wordle](https://www.nytimes.com/games/wordle/index.html)?
Use this chrome extension to aid you, with suggestions as you progress through the puzzle!

Setup:
1. Download the source
2. Unzip it
3. Go to chrome://extensions
4. Click on "Load Unpacked"
5. Upload the folder
6. Pin the extension

And it's all done!
